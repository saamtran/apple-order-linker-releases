# Apple Order Linker

Downloads for the Apple Order Linker desktop app.

## Mac

Requires a Mac with Apple Silicon (M1 or newer) and Google Chrome.

1. Download `Apple-Order-Linker-mac.zip` from the [latest release](https://github.com/saamtran/apple-order-linker-releases/releases/latest).
2. Unzip it and move **Apple Order Linker** to your Applications folder.
3. First launch:
   - **macOS 15 or newer:** open the app once. When it is blocked, go to System Settings → Privacy & Security, scroll down, and click **Open Anyway**.
   - **Older macOS:** right-click the app, choose **Open**, then click **Open** again.

## Updates

The app checks for updates and installs them for you. There is no need to download new versions here by hand.
