# Orchard

Downloads for the Orchard desktop app (formerly Apple Order Linker).

## Mac

Requires a Mac with Apple Silicon (M1 or newer) and Google Chrome.

1. Download `Orchard-mac.zip` from the [latest release](https://github.com/saamtran/orchard-releases/releases/latest). (Releases before v0.2.0 call it `Apple-Order-Linker-mac.zip`.)
2. Unzip it and move **Orchard** to your Applications folder.
3. First launch:
   - **macOS 15 or newer:** open the app once. When it is blocked, go to System Settings → Privacy & Security, scroll down, and click **Open Anyway**.
   - **Older macOS:** right-click the app, choose **Open**, then click **Open** again.

## Updates

The app checks for updates and installs them for you. There is no need to download new versions here by hand.

If you already use Apple Order Linker, just update from inside the app: it becomes Orchard and keeps your queue, Apple session, settings, proxies and license. Each release also includes `Apple-Order-Linker-*.zip` copies so older versions can still update themselves; you don't need to download those.
